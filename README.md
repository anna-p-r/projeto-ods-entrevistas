# EcoBem

Site acadêmico de extensão universitária relacionado à **ODS 3 — Saúde e Bem-Estar** e à disciplina de Integração de Competências em Gestão de Recursos Humanos.

## Como visualizar

Abra o arquivo `index.html` no navegador. O site funciona localmente e não exige instalação.

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `ecobem`.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Entre em **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o link de publicação.

## Funcionalidades

- Layout responsivo para celular e computador
- Tema claro/escuro
- Janelas com orientações de ergonomia, pausas, energia e saúde mental
- Cronômetro de pausa guiada
- Checklist com salvamento local
- Check-in educativo de bem-estar
- Plano semanal com salvamento local
- Seção de boas práticas para instituições e RH
- Referências oficiais

## Observação ética

O site tem finalidade educativa e preventiva. Não realiza diagnóstico nem substitui atendimento profissional. Os dados do diagnóstico apresentados são simulados para fins acadêmicos.
